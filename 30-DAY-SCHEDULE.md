A standalone, time-balanced scheduling table for the existing **40-activity Emery-only course**. Source of truth: [SYLLABUS.md](SYLLABUS.md). No activity, prerequisite, reading, lesson structure, or completion standard is changed here.

- **Pace:** 30 consecutive study days × 150 focused minutes/day (2h 30m).
- **Required course time:** 48h 35m = 11h 50m reading + 36h 45m existing exercises; this matches the syllabus estimate.
- **Unstructured personal Pebble project time:** 26h 25m total. Use any project you already have in progress. This column introduces **no activities, requirements, or assessment**.
- **Timing:** Suggested allocations, not independent activity completion criteria. “Begin” and “finish” refer to the same existing activity across days.
- **Order:** Original five phases and individual prerequisites preserved. Do not mark an activity complete without its existing required evidence and Emery verification.
- **Scope:** Reading references existing course guides/modules; exercise IDs refer to the existing `lessons/<ID>/` directories. Days are relative so the sample works from any start date.

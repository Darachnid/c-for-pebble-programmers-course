# 30-Day Sample Study Schedule — C for Pebble Programmers

This is a **sample time-balanced allocation**, not a new curriculum. It retains all 41 required lessons, their original duration estimates, all prerequisites and the independent-app capstone, now using the sequential numbering `1A` through `41A`. Letter suffixes do not dictate order. [Current syllabus](SYLLABUS.md) · [41-lesson sequence](curriculum/course-design/integrated-sequence.md) · [Legacy ID map](taskwarrior/legacy-id-map.json).

**Pace:** 30 consecutive study days, **150 focused minutes daily**, dividing each session between reading, existing exercises, and independent personal Pebble projects. Every assigned lesson is scheduled in prerequisite order. Normal/boundary tests and completion evidence are still required even if an estimate proves optimistic; use personal-project time as overflow if necessary.

**Time allocation:** 710 minutes reading (11h 50m); 2,445 minutes assigned exercises (40h 45m); 1,345 minutes optional own-project time (22h 25m), for 4,500 minutes total (75h). This preserves the previous sample's overall reading estimate while accounting for the new four-hour capstone.

In the reading column, use the **existing local module, companion guide or API reference linked from that lesson**, not any new reading or generated activity. “Begin”, “Continue” and “Finish” simply divide an existing lesson over sessions; do not mark it complete until the stated acceptance criteria and two competency scores are met.

## Scope and completion rules

- The schedule is **illustrative**, not a hard 30-day guarantee. The 52h 35m required-course estimate excludes optional own-project time.
- Readings and exercises are **not** extra assignments. Their time slices divide each existing lesson's estimated effort.
- All 41 IDs appear in the order specified by the integrated syllabus. No alphabetic A-before-B assumption is made.
- Physical hardware-dependent checks should be marked pending when not verified; do not invent emulator results.
- Use a personal Git branch/copy, retain independent work evidence, and do not rely on AI-generated exercise solutions.

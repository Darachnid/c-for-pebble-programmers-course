**Primary competency:** Algorithmic Thinking · **Supporting competency:** UI Design · **Estimate:** 75m · **Prerequisites:** 28D, 18F · **Platform:** Emery, SDK 4.33.1

## Exact local example

The [starter/](starter/) folder contains a full `package.json`, `wscript`, `src/c/main.c` and any extra resources needed. It is a **prior-stage checkpoint**, not the solution to the current exercise. Start here instead of cloning an external repository.

**Project history:** 28D → 29E → 33F. Commit your own solution in a separate Git working branch/copy. Later reference checkpoints illustrate completed earlier features; do not simply copy them backwards.

## SDK APIs

`GPathInfo, gpath_create, gpath_move_to` — [Official C API reference](https://developer.repebble.com/docs/c/Graphics/Drawing_Paths/).

## Activity

Build a vertex-based species symbol using GPath; move it on selection and destroy it correctly.

## Evidence-based completion

A graphics path appears in two positions and ownership/bounds are demonstrated. Score **both primary and supporting competencies at 2 or 3** using the [four-level rubric](../../curriculum/course-design/learning-outcomes-and-assessment.md). Keep an independent API explanation, original Git diff, running evidence, normal and failure/boundary tests, and a brief reflection. Do not treat emulator-only logs as hardware verification.

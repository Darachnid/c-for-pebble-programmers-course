# Official Pebble SDK watchface tutorial (MIT source snapshot)

This is the exact unmodified upstream C source from [pebble-examples/watchface-tutorial](https://github.com/pebble-examples/watchface-tutorial). Its old tutorial uses additional assets and is included for reading/provenance only, **not** as a build target. For this lesson, use the single-layer Emery starter under `src/c/main.c`. The licensed SDK source is intentionally more advanced, and may contain features not yet assigned.

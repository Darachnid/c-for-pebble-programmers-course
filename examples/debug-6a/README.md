# 6A — Compiler diagnostic challenge (LOW)

**This project is intentionally broken. It should not compile until you diagnose it.**

Task: Run `pebble build`, record the *first compiler error*, identify the source file and line, and correct the minimum necessary syntax. Then build and run using `pebble install --emulator emery`.

Evidence: original compiler error, your explanation, and successful build. The compiler should tell you approximately where to look; avoid changing unrelated code.

This exercise contains **exactly one intentionally introduced syntax fault**. Do not consult the clean time-only starter until you've explained your fix.
